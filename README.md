# Xhaus Journal

A full-stack personal digital journal built with React, TypeScript, Spring Boot, and PostgreSQL.

## Project Status

🚧 **Under Development — V1**

## About

Xhaus Journal is a personal online journal where I can write and publish daily entries about my life, experiences, activities, thoughts, and things I've worked on.

The website will have a public-facing journal that visitors can read, while journal management and publishing will require authentication.
